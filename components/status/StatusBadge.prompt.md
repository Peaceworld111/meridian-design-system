Status pill — the single way state is shown across both the portal and the back office.

```jsx
<StatusBadge tone="neutral" progress="7 / 12">确认中</StatusBadge>
<StatusBadge tone="warning">等待审批</StatusBadge>
<StatusBadge tone="positive">已入账</StatusBadge>
<StatusBadge tone="negative">付款失败</StatusBadge>
```
