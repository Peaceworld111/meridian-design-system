# Meridian 设计系统

一套面向**企业稳定币出入金与全球代付**平台的设计系统。它服务两个产品面：

- **客户端 Portal** — 企业客户自助：开户(KYB) → 充值 USDT → 兑换币/法币 → 付款/提现 → 审批 → 对账。
- **后台 Admin** — 内部合规、风控、Treasury、运营：KYB 审核、出金人工复核、交易监控、风控告警、资金与储备、费率配置、审计。

两面共用同一套 token 与组件，差别只在密度、信息量和键盘操作。

## 来源

本设计系统从同工程内的高保真原型提炼，不是从外部代码库或 Figma 导入的。原始来源：

- 原型页面：项目内的 `*.dc.html`（`总览` `余额` `充值` `兑换` `提现` `模式-新建付款` `审批` `收款人` `结单` `信任与合规`，以及 `后台-*` 全套）。
- 规范页：`设计系统-基础.dc.html`、`设计系统-业务组件.dc.html` —— **这两页是本系统的直接依据**，色值、字级、状态词表、金额规则都从其中原样搬入。
- 开发交接包：`design_handoff_stablecoin_ramp/`（给 Claude Code 的实现说明）。
- 无外部 Figma 链接、无 GitHub 仓库、无客户提供的品牌资料。

## CONTENT FUNDAMENTALS

这是一款替人管钱的产品。文案的唯一任务是：**让人随时知道钱在哪、下一步会发生什么、什么时候到。**

**人称与语气。** 称"你"，不称"您"——平等、务实，不谄媚。不道歉("非常抱歉"从不出现)，不用感叹号，不用 emoji，不用"轻松""秒到""安心"这类营销词。中文为主，行业术语(SEPA / SWIFT / UBO / Travel Rule / MLRO)保留英文原样，不硬译。

**按钮说明动作与后果，不说"提交"。**
- ✓ `确认付款 5,000.00 EUR` / `批准 5,003.00 EUR` / `放行` / `提交审核（全部完成后可用）`
- ✗ `提交` / `确定` / `继续`

**错误三段式：发生了什么 · 为什么 · 你可以做什么。** 资金相关的错误必须交代钱的去向。
- ✓ `付款失败。收款账号无效，5,003.00 EUR 已退回可用余额，手续费已退还。修改收款人后可重试。`
- ✗ `操作失败，请稍后再试`

**等待要给时间和责任人。** `等待审批 · Chan Wai 已收到通知` / `平台审核通常 1 小时内` / `预计到账 9月8日前` / `SLA 剩余 6 小时`。没有 ETA 的等待等于坏消息。

**状态是一个词，进度是灰色小字。** `确认中` + `· 7 / 12`，不写"正在确认中(7/12)…"。

**同一件事有两种说法**：客户看到"发生了什么 + 接下来会怎样"，后台看到原始状态名，客户文案作副注。完整词表见规范卡片 *Status Vocabulary*，示例：

| 场景 | 客户看到 | 内部 |
| --- | --- | --- |
| 入金 | 确认中 · 7 / 12 | Confirming |
| 入金 | 已暂停 · 正在审核，我们会联系你 | Held |
| 付款 | 等待审批 · 等待 Chan Wai | Pending Approval |
| 付款 | 已退汇 · 收款行退回，已扣退汇费 | Returned |
| 开户 | 需要补充资料 · 3 项 | RFI |

**数字与币种永远成对。** `5,000.00 EUR`，不是 `€5,000` 也不是 `5000`。折算值另起一行加 `≈`。

**大小写与标点。** 中文正文用中文标点；金额、代码、单号用半角。标题不加句号，说明句加句号。链接文案是名词或动宾短语(`查看结单`、`浏览器 ↗`)，不是"点击这里"。

## VISUAL FOUNDATIONS

**总体气质**：银行后台的密度 + 现代 SaaS 的克制。白底、冷灰、一处蓝。没有渐变、没有插画、没有摄影图、没有品牌纹理——这个产品的"视觉"就是**排版、对齐和留白**。

**色彩。** 基底是带一点蓝的冷灰(`#F5F6FA` 页面 / `#FFFFFF` 卡片 / `#EEF0F5` 沉底)，文字三级 `#14213D` → `#4A5875` → `#8A94AB`。主色 `#2554E6` **只用于可以点的东西**：链接、主按钮、选中态、进度条。语义色只表达状态四义：中性(系统在处理)、警告(需要你处理)、成功(终态好)、失败(终态坏)。**资金方向用 `+` / `−`(U+2212)表达，绝不用红绿**——这是本系统最硬的一条规则。全场最多两种背景色(页面灰 + 卡片白)。

**字体。** IBM Plex Sans + Noto Sans SC，三个字重(400/500/600)。等宽 IBM Plex Mono **只用于标识**：地址、哈希、单号、Key、IBAN、时间戳。8 档字级(12 / 13 / 14 / 16 / 20 / 24 / 32 / 44)，正文 14/20，表格 13/18。**所有数字 `tabular-nums`，金额字重 500**，hero 金额带 `-0.01em` 字距。金额四档尺寸：表格 13 · 详情 16 · 确认页 24 · 总览 32。

**间距。** 4pt 网格，10 档。卡片内边距 20/24，卡片之间 16，分区之间 40，内容区 padding 24。控件高度 24 / 26 / 32 / 36 / 40，表格行高舒适 44 / 紧凑 36(后台默认紧凑)。

**背景。** 纯色。没有图片、没有全出血视觉、没有重复纹理、没有渐变。唯一的"图形"是币种/网络图标和一个倒计时圆环。

**边框 vs 阴影。** 用 1px `#E1E5EE` 分区，**卡片没有阴影**。阴影只属于浮层：下拉 `0 4px 12px rgba(20,33,61,.10)`，弹窗/抽屉 `0 12px 32px rgba(20,33,61,.16)`。遮罩 `rgba(20,33,61,.18)`——不用模糊，因为下面的数字要能看见。

**圆角。** 只有三档：4px(输入、按钮、徽章) / 8px(卡片、抽屉内面板) / 12px(弹窗、移动端底部面板)。圆形只给头像、状态点、步骤序号和币种图标。

**卡片长什么样。** 白底 + 1px 边 + 8px 角 + 无阴影。有标题时标题行 12/16 padding + 下边框；表格类卡片内容贴边(`pad={false}`)。

**hover / 按下 / 焦点。** hover 是更深一点的底色，不是位移也不是阴影：行 `#F8F9FC`、次级按钮 `#EEF0F5`、主按钮 `#1C45C4`。选中行 `#E8EEFD`，选中卡 `#F8FAFF`。焦点是 3px `#E8EEFD` 光环 + 主色边。按下不做缩放。禁用是 `#EEF0F5` 底 + `#8A94AB` 字 + `not-allowed`。

**动效。** 120–150ms，`cubic-bezier(.2,0,.2,1)`，只做颜色和位移。没有弹跳、没有页面转场淡入、没有骨架屏微光。唯一的持续动画是报价倒计时环(`stroke-dashoffset`，1s linear)——因为它表示的是真实流逝的时间。

**透明与模糊。** 几乎不用。只有遮罩的 18% 黑蓝，和未来步骤的 `opacity:.6`。**正文永远不用半透明色**——金额必须足额对比度。

**布局。** 固定左侧栏(客户端 240 / 后台 220) + 固定 52px 顶栏 + 滚动内容区。表单 max-width 640/760，列表 1040–1200。抽屉从右侧滑入，480(客户端) / 640(后台) / 720(宽审核)，`min(宽度, 94vw)`。表格外层永远 `overflow-x:auto` + `min-width:600px`。

**图像的色调。** 不适用——本系统不使用摄影或插画。若将来引入，应为冷调、低饱和、无颗粒。

## ICONOGRAPHY

**没有通用图标字体，也没有图标库。** 界面里几乎不出现装饰性图标——导航是纯文字，操作是纯文字按钮。这是刻意的：密集的金融表格里，图标比文字更慢。

实际使用的图形只有四类，全部是 `assets/icons/` 下的 SVG：

| 类别 | 目录 | 用法 |
| --- | --- | --- |
| 代币 | `token/` | usdt · usdc · eth · trx · sol · bnb · btc，另有 `-mono` 单色版 |
| 网络 | `network/` | tron · ethereum · solana · base · polygon · arbitrum · bsc，另有 `-mono` |
| 法币 | `flag/` | 圆形国旗，按 ISO 4217 命名(usd/eur/gbp/hkd/sgd/jpy/aud/cad/chf/aed/cny/krw) |
| 通道与品牌 | `brand/` | sepa · swift · visa · mastercard · tether · circle · coinbase · binance · wise 等，单色 Ink |

规则：统一圆形、同尺寸(16 / 20 / 24 / 32)；**彩色版只用在余额卡、兑换卡、确认页**，密集表格与徽章用 `-mono`；链相关场景是"代币 + 右下角网络徽章"(12px，1.5px 白描边)；**图标永远配币种代码文字**，不单独出现。发行方标志是他人商标，不改色、不变形。

界面里另有五个手绘的功能性 SVG(通知铃铛、兑换方向箭头、展开箭头、失败叉、倒计时环)——它们是控件的一部分，不是图标集。Unicode 字符被当作图标用：`✓` `◦` `▾` `↗` `×` `—`。**不使用 emoji。**

**Logo：来源里没有提供品牌标志。** 现在所有出现标记的位置用的是一个占位方块(深色底 + 白色字母 M) + 文字 "Meridian"。有正式 logo 时替换这两处(`ui_kits/portal/AppShell.jsx`、`ui_kits/admin/AdminShell.jsx`)并放入 `assets/`。

## 使用方式

```html
<link rel="stylesheet" href="styles.css">
```

组件全部读 CSS 变量，不带任何 npm 依赖；改主题只需覆盖 `:root` 上的自定义属性。
