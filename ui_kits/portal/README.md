# UI kit · 客户端 Portal

企业客户自助界面的高保真复刻。三屏可点击：

| 屏 | 文件 | 演示的东西 |
| --- | --- | --- |
| 主框架 | `AppShell.jsx` | 240px 侧栏（审批带待办数）、52px 顶栏（主体切换 + 铃铛通知）、24px 内容区 |
| 总览 | `OverviewScreen.jsx` | 总资产 hero 金额、可用/预留/在途三栏、币种表（行内兑换/付款）、近期交易 |
| 兑换 | `ExchangeScreen.jsx` | 双侧独立币种选择、余额不足红字校验并禁用报价、30 秒锁价报价卡、过期变刷新 |
| 付款 | `PaymentsScreen.jsx` | tabs + 紧凑表格 + 分页；点行开右侧抽屉（摘要 / 审批链 / 时间线） |

一致的账本数据贯穿三屏：EUR 可用 13,281.00 · 预留 5,003.00 · USDT 在途 5,000.00 · 总资产 19,969.87 USD。

未收录的屏（充值、提现、收款人、结单、开户、设置）在原型工程里有完整设计，本 kit 只演示主框架与三条主路径；侧栏点这些项会显示占位说明。
