# UI kit · 后台 Admin

内部运营/合规界面的高保真复刻，演示"队列作业"这一后台核心范式。

| 屏 | 文件 | 演示的东西 |
| --- | --- | --- |
| 主框架 | `AdminShell.jsx` | 220px 分组侧栏（合规 / 风控 / Treasury，带待办数）、全局搜索顶栏、当前操作人与角色 |
| 出金复核 | `PayoutReviewScreen.jsx` | 四眼原则横幅、队列头（tabs + 快捷键）、紧凑表格（风险徽章、拦截规则、等待时长）、低风险行内快捷放行、640px 复核抽屉（拦截原因 / 核验结果 / 审计记录）、放行后 toast 与队列减一 |

后台与客户端共用同一套 tokens 与组件，差异只在密度（行高 36）、信息量与快捷键。

KYB 审核台、客户 360、交易监控、风控告警、资金储备、费率配置在原型工程里有完整设计，未纳入本 kit。
